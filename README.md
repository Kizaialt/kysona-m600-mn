# KYSONA M600 — Монгол хэлний багц

KYSONA M600 / M600 V2 хулганы Windows драйверыг **монгол хэл дээр**
ажиллуулах хэлний багц.

Драйверын программыг (`Mouse Drive Beta.exe`) **өөрчлөхгүй**. Драйвер өөрөө
`Language` хавтас доторх XML файлуудыг уншиж хэлний жагсаалтаа үүсгэдэг тул
зөвхөн шинэ файл нэмж өгч байгаа хэрэг.

> Хамаарах: [WIN 60/68 HE веб драйвер](https://kizaialt.github.io/winhe-driver/) ·
> [AULA F-цуврал](https://github.com/Kizaialt/aula-fseries-mn).
> Гурвуулаа ижил нэр томьёо ашигласан.

---

## Яагаад энэ арга вэ

Драйверыг задалж үзэхэд:

```
app\Language\0-English.xml     англи мөрүүд
app\Language\1-한국어.xml       солонгос мөрүүд
app\Language\2-简体中文.xml     хятад (зөвхөн V2 дээр)
app\Mouse Drive Beta.exe       программ өөрөө
app\Config.ini                 төхөөрөмжийн тохиргоо (хэлтэй холбоогүй)
```

`Mouse Drive Beta.exe` дотор `GetLanguageFileCount`, `SaveLanguageIndex`,
`gLanguageFile`, `*.xml` гэсэн мөрүүд байна — өөрөөр хэлбэл программ нь
`Language` хавтас доторх XML файлуудыг **өөрөө тоолж жагсаадаг**.

Тиймээс монгол хэл нэмэх нь **ганц файл нэмэх** явдал:

```
app\Language\2-Монгол.xml      (V2 дээр 3-Монгол.xml)
```

Тохиргооны файл ч засах шаардлагагүй. Программын exe хөндөгдөхгүй тул:

- Windows SmartScreen / антивирусын асуудал гарахгүй
- Хэрэглэгч KYSONA-гийн жинхэнэ драйверыг суулгана
- Драйвер шинэчлэгдэхэд багцыг дахин үүсгэхэд л хангалттай

Файлын нэр `<дугаар>-<Хэлний нэр>.xml` бөгөөд XML-ийн үндсэн элемент нь
хэлний нэр байдаг (`<English>`, `<한국어>` → `<Монгол>`).

## Багц

| Хувилбар | Файл | Багц |
|---|---|---|
| M600 (анхны) | `2-Монгол.xml` | `dist/KYSONA_M600_driver_mn.zip` |
| M600 V2 | `3-Монгол.xml` | `dist/KYSONA_M600_V2_driver_mn.zip` |

Хоёр хувилбарын англи мөрүүд **яг ижил** (288 мөр) тул нэг орчуулга
хоёуланд нь тохирно. Ялгаа нь зөвхөн файлын дугаар — V2 дээр хятад хэл
нэмэлтээр байдаг. Суулгах скрипт нь дугаарыг компьютер дээр нь **өөрөө
тооцоолдог** тул аль ч хувилбар дээр зөв ажиллана.

M617, Aztec зэрэг загварууд ижил драйвер ашигладаг тул мөн ажиллана.

## Хэрэглэгч хэрхэн суулгах вэ

1. KYSONA-гийн жинхэнэ драйверыг суулгана:
   <https://shop.kysona.com/pages/downloads>
2. `_mn.zip`-ийг задалж **`install-mn.bat`** дээр хоёр товшино.
   Администратор эрх асуувал зөвшөөрнө.
3. Драйверыг нээгээд **Setting → Language → Монгол**.

Скрипт нь драйверыг өөрөө хайж олж, сул дугаарыг тооцоолж, файлыг хуулна.
Дахин ажиллуулахад давхардуулахгүй. Буцаахын тулд `Language` хавтаснаас
`*-Монгол.xml` файлыг устгахад хангалттай.

## Багцыг дахин үүсгэх

```bash
python tools/build.py installers/*.exe
```

Шаардлага: [innoextract](https://constexpr.org/innoextract/)

```bash
winget install --id dscharrer.innoextract -e
```

M600 V2 нь `.rar` дотор ирдэг тул эхлээд задлаад `.exe`-г `installers/`
дотор хийнэ.

### Орчуулга засах

Бүх текст **`tools/mn.json`** дотор байна. Англи эх мөрөөр түлхүүрлэсэн —
учир нь драйвер нь элементийн нэрийг давтдаг (`KeyFunction` бүр `<name>`
гэж нэрлэгдсэн).

- `strings` — орчуулга
- `_keep_as_is` — орчуулахгүй үлдээх утгууд (`1mm`, `30sec`, `0ms`, `400`,
  `LP`, `HP` гэх мэт)
- `_font_size` — драйверын үсгийн хэмжээ (англи 9.5, солонгос 10.5)

`ComboBoxName` элементүүд нь **удирдлагын нэр** болохоос текст биш тул
хэзээ ч орчуулагддаггүй — `build.py` үүнийг хамгаалдаг.

### Шалгах

```bash
python tools/verify.py .work/<MODEL>/app/Language/0-English.xml dist/<MODEL>/2-Монгол.xml
python tools/inspect_driver.py ".work/<MODEL>/app/Mouse Drive Beta.exe"
```

## Шалгагдсан ба шалгагдаагүй зүйл

**Шалгасан:**
- Элементийн бүтэц эх файлтай яг ижил (288 мөр, ижил дараалал)
- UTF-8 + BOM, CRLF — эх файлын формат хэвээр
- `ComboBoxName` удирдлагын нэрс хөндөгдөөгүй
- Тоо, нэгжүүд (53 утга) хэвээр
- Орчуулагдаагүй мөр **байхгүй** (219 кирилл утга)
- Суулгах скрипт: дугаарыг зөв сонгоно, дахин ажиллуулахад давхардахгүй,
  эх хэлний файлууд хэвээр

**Шалгаагүй — жинхэнэ хулгана дээр туршина уу:**
- Драйвер монгол текстийг хэрхэн харуулах (фонт, урт мөр багтах эсэх)
- `Setting → Language` цэсэнд "Монгол" гарч ирэх эсэх

---

## Веб драйверын тухай

KYSONA-гийн сайт дээр `qmk.top` гэсэн веб драйвер бий. Гэвч тэр нь 2.1 МБ
React программ бөгөөд бүх текст нь кодын дотор хатуу бичигдсэн, хэлний
систем огт байхгүй (`translate="no"` гэж тавьсан). Тиймээс тэндээс биш,
албан ёсны Windows драйвераас нь орчуулав.

## Эрх зүйн тайлбар

Энэ бол KYSONA-гийн драйверт **нэмэлт хэлний файл** бөгөөд программыг
өөрчлөөгүй. Драйверыг хэрэглэгч KYSONA-гийн албан ёсны сайтаас татаж
суулгана. Асуудал гарвал KYSONA-тай холбогдоно уу.
